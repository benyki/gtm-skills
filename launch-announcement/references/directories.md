## How to work the tail

The tail is **not launch-day work**. Doing it on Day 0 steals attention from the
platforms that decide whether the launch worked.

1. **Week 2, one sitting.** Write the reusable assets once: name, 60-char tagline, 160-char description, ~500-char description, logo (square, transparent PNG), one hero screenshot, category tags, pricing line, contact email
2. **Filter first.** Cross out anything that doesn't match the product — an AI directory listing for a non-AI product is a dead link that never sends anyone
3. **Go in weight order** (worklist above), then alphabetically through what's left. Log each submission with its date and status. Many have review queues measured in weeks
4. **Claim what you're owed.** Several of these promise a backlink in exchange for a badge on your site — and `[E]`'s TinyLaunch experience is that it doesn't happen automatically. If a backlink is the reason you submitted, follow up
5. **Never pay to be listed** in a generic directory on a first launch. Paid placement on TAAFT or a queue-skip on Uneed can be worth it; a $49 listing on a directory nobody visits is not
6. **Stop when it stops paying.** Check referral traffic after two weeks. If the tail sent 11 visits, that's your answer for next time — and that number belongs in the shiplist's Log so the next launch doesn't repeat it
