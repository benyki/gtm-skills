# Etymology source notes — seed threads

The 10 seed threads use well-attested etymologies. Verify any *new* word the same way before adding
it (Online Etymology Dictionary = etymonline.com, OED, Wiktionary). Notes below flag where the
common telling overstates things, so the copy stays honest.

| Word | Core claim | Notes / honesty flags |
|---|---|---|
| **salary** | Latin *salarium*, from *sal* "salt"; an allowance connected to salt. | The *sal* → *salarium* link is solid. The popular "Roman soldiers were paid in salt" is **disputed** — copy says "an allowance bound up with salt" / "salt money," not that salt was handed over. "Worth your salt" reinforces, harmlessly. |
| **quarantine** | Italian *quaranta giorni*, "forty days"; Venice/Ragusa plague-ship isolation, 1300s. | Solid. Earlier 30-day *trentino* → extended to 40. Ragusa (Dubrovnik) 1377 is the usual cited origin. |
| **companion** | Latin *com-* "with" + *panis* "bread" — one you share bread with. | Solid (via Late Latin *companio*, calque of a Germanic term). *pain*/pantry tie-in is correct. |
| **muscle** | Latin *musculus* "little mouse." | Solid. *mussel* shares the root; the computer *mouse* is named for resemblance, same imagery — copy says "belongs to the same family," which is fair. |
| **sarcasm** | Greek *sarkazein* "to tear flesh," from *sarx* "flesh." | Solid. *sarcophagus* = "flesh-eater" is correct and shares *sarx*. |
| **window** | Old Norse *vindauga*, *vindr* "wind" + *auga* "eye." | Solid. Replaced Old English *eagþyrl* (eye-hole) / *eagduru* (eye-door). |
| **clue** | Variant of *clew* "ball of thread"; Theseus/Ariadne labyrinth → metaphor for solving a mystery. | Solid. The detective sense generalizes from "thread out of a maze" by the 1600s. |
| **disaster** | Italian *disastro*, *dis-* "bad" + *astro* "star" — "ill-starred," astrological. | Solid. Via French *désastre* into English ~1590s. |
| **nightmare** | "mare" = Old English *mære*, a crushing night-demon; not a horse. | Solid. Maps onto sleep paralysis. The horse "mare" is an unrelated word — copy makes that explicit. |
| **avocado** | Nahuatl *āhuacatl* (also "testicle"); Spanish *aguacate* → *avocado* (echo of *abogado* "lawyer"). Guacamole < *āhuacamōlli*. | The "testicle" sense of *āhuacatl* is **attested**, though some scholars treat the dual meaning cautiously — copy hedges with "carried a second meaning" / "probably for the shape." *abogado* folk-reshaping is the standard account. |

## Disqualified / handle-with-care words

- **sincere** — the "sine cera / without wax" story is a **folk etymology and false**. Only use if the
  thread's whole point is to debunk it.
- **posh** ("port out, starboard home"), **golf** (acronym), **the whole nine yards**, **rule of thumb**
  — popular but unverified or debunked. Avoid unless debunking.
